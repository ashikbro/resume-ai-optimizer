# Resume AI Optimizer

**Tailor resumes to job descriptions without inventing experience.**

Deterministic keyword matching that reports matched and missing terms while preserving exact resume sentences as evidence.

## What it does now

- Plain-text keyword matching against a job description
- Shows matched and missing terms
- Keeps original resume sentences as evidence
- Does not invent employers, titles, dates, metrics, or responsibilities

## Quick start

```sh
python -m venv .venv
.venv/bin/pip install pytest
PYTHONPATH=src .venv/bin/pytest
```

## Principles

- Never invent experience
- Suggestions must be traceable to source text
- User confirmation required before any change
